# Инструкция оператора

## Перед сменой

1. Сервер запущен: в браузере открывается `http://<сервер>:8080`, вход по логину и паролю.
   Зелёная точка «сервер на связи» справа вверху.
2. Подготовлены тестовые microSD (по одной на плату, все одной версии — версия видна в верхней панели).
3. Этикетки с серийниками печатаются только после PASS, на плату их клеит оператор.

## Проверка стенда (golden sample)

1. Эталонную плату (помечена ★) вставить в стенд с тестовой картой, подключить Ethernet и питание.
2. Выделить её квадрат (или ничего не выделять, если плата помечена ★) и нажать **«Проверка стенда»**.
3. Итог должен быть PASS. При FAIL партию не запускать, позвать инженера. Итог проверки записывается в следующую партию.

Пометить плату как эталонную: карточка платы → «Сделать golden sample».

## Партия

1. Вставить microSD во все платы, подключить Ethernet, затем питание.
2. Через 1–2 минуты в сетке появятся синие квадраты «готов». Сверить счётчик «Online» с числом плат.
3. **«Выбрать все online»**, затем режим:
   - **«Только тесты»** — RAM, NET, SD-NAND; образ не пишется. Флажок «Полный паттерн-тест SD-NAND» — долгий полный тест.
   - **«Тесты + прошивка»** — после PASS всех тестов пишет финальный образ.
   - **«Только прошивка»** — для уже протестированных плат при смене образа.
4. Подтвердить в окне. Квадраты станут жёлтыми, в полоске этапов видно, что идёт.

## Чтение квадрата

| Рамка | Значение |
|---|---|
| синяя | готов, задания нет |
| жёлтая | в работе или ждёт BOOT (таймер) |
| зелёная | PASS по режиму |
| красная | FAIL; причина в строке под полоской (`RAM: 2 err`, `NET: no carrier`…) |
| серая пунктирная | нет связи (время последнего сигнала); это **не** результат теста |
| серая сплошная с `!` | прервано: плату нужно прогнать снова |

Полоска: RAM NET SD FLASH BOOT. Серый — не запускался, жёлтый — идёт, зелёный — PASS, красный — FAIL, штриховка — пропущен.

## Этап BOOT (после прошивки)

Когда квадрат жёлтый с подписью «ждём BOOT»: выключить плату, **извлечь microSD**, включить.
Плата загрузится с SD-NAND и сама сообщит серверу; квадрат станет зелёным. Если отчёта нет до
конца таймера — красный `BOOT: no report`.

## Остановка

**«Остановить»** с выбранными квадратами останавливает их, без выбора — всю текущую партию.
До начала записи это отмена. Во время прошивки плата получает статус «прервано», её SD-NAND
непригодна до повторной прошивки: запустить для неё **«Только прошивка»**.

Пропало питание или сеть во время прошивки — так же: «Только прошивка» после возврата платы.

## После партии

- **«Экспорт CSV»** — отчёт по текущей партии; история: «История партий» (CSV/JSON, этикетки).
- Этикетка: карточка платы → «Этикетка» (откроется печать, 50×30 мм, QR с серийником, партией и датой).
- Повтор для FAIL-плат: выделить их щелчком и нажать нужный режим («Только тесты», «Тесты + прошивка»). После запуска выбор снимается; платы, где задание уже идёт, в новую партию не попадают.
- Выключить платы, извлечь microSD, сложить карты.

## Безопасное завершение

Перед выключением сервера дождаться, чтобы не было жёлтых квадратов (или нажать «Остановить» и
дождаться итогов). Сервер останавливается `systemctl stop napi-factory-server`; данные в одном
файле `/var/lib/napi-factory/factory.db`.
